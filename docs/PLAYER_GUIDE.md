# 频道、设备与加载配额

这里的“传输频道”与 AE2 的 ME 频道不同。一个传输频道可在 N 台独立子服、多维度和多区块中绑定设备，资源是共享总量及独占划拨，不是广播复制。

放置方块的玩家是 **设备主人**；创建频道的玩家是 **频道主人**，两个字段分开保存。频道主人邀请成员，不自动获得成员设备的控制权。普通成员只能配置自己的设备。管道通常没有玩家身份；能力访问依据设备主人的有效频道绑定权限，因此成员在受保护区域放置接收端，意味着当地机器能使用接收资源。区域保护由其他机制负责。

## 界面

右键自己的方块，界面包含设备、频道、邀请、成员、配额、端点六页。可配置每种已安装资源的方向、六侧、每 tick 速率、过滤器、EU 电压/安培和 AE 物资网关。滤器匹配注册 ID，当前主要限制本地输入；它不是远端库存查询语言，也未实现按组件表达式过滤。

安装 AE2 后增加“库存”页；需先在设备页开启 AE 物资桥。该页将本地立即可取、远端已知、独占预留、在途和不可达分开显示，完整数字也在条目提示中。同名不同组件以载荷哈希前缀区分。列表每批八条，可浏览下一批；选中资源，输入正整数数量并调货。操作只确认需求已记录，真正到货后才进入同步 ME 库存。

每设备最多八个待分配需求，默认六十秒期限；“取消待分配需求”取消当前列表中最新的未分配需求，不退款已划拨部分。资源方向必须允许接收，原生 ME 网络须有电和频道；满载、无货、权限暂停或后端故障不会产生可同步提取的远端余额。快照超过五秒标记陈旧并停用调货。AE 原生同步实际提取不足会异步请求短缺，模拟提取没有网络/数据库副作用。

SEND 自动从相邻容器有界抽入，RECEIVE/BOTH 自动输出已到货库存。BOTH 可接受管道输入，但不自动抽回相邻输出容器，避免循环搬运；想自动同时收发请使用两个分开的设备。明确部分接收的剩余仍属于原接收凭证；不能因换频道或重试把它转换为新的发送资源。

异步操作先显示“处理中”，收到服务端最终结果才显示成功；超过等待期限显示“状态待确认”，需要刷新诊断，不能据此认为操作失败并退款。界面和命令都由服务端重新授权。GUI 列表目前每次最多显示 64 条，超过该数量时通过命令/管理查询；没有声称实现无上限分页。

频道私有邀请制，邀请默认七天过期，可接受/拒绝/撤销。转移通过另一种邀请由新主人接受，在同一事务内替换唯一 owner；原主人不能直接退出留下无主频道。删除前冻结、排空、解绑，并检查余额、独占划拨、热交换和绑定端点；有未完成资产则拒绝删除。

## 玩家命令

```text
/ct status
/ct create 名称
/ct channels
/ct invite <channel_uuid> <target_player_uuid>
/ct invites
/ct accept <invite_uuid>
/ct decline <invite_uuid>
/ct revoke <invite_uuid>
/ct transfer <channel_uuid> <new_owner_uuid>
/ct members <channel_uuid>
/ct remove <channel_uuid> <member_uuid>
/ct leave <channel_uuid>
/ct permissions <channel_uuid> <member_uuid> <mask>
/ct rename <channel_uuid> 新名称
/ct bind <channel_uuid>
/ct unbind
/ct mode cross_tesseract:fe SEND
/ct quota
/ct load
/ct off <device_uuid>
```

bind/unbind/mode/load 要面向自己的方块，距离上限 8 格。权限位：查看 1、发送 2、接收 4、修改频道设置 8、邀请/移除 16；普通成员默认 7，主人 31。所有 SQL 资产提交都重新检查权限及频道状态；GUI 隐藏按钮不是安全边界。

正常权限缓存每 2 秒刷新，能力授权最多有效 3 秒；网络分区不能瞬时撤销所有本地动作。SQL 扣加余额和配额批准从不无限期依赖旧缓存。已独占划拨资源撤权后保留在原阶段并暂停；不会自动加回余额造成重复退款。

## 全群组加载配额

默认每玩家最多启用 2 个超立方体，跨子服、跨维度累计，同区块两个设备也算 2。加入别人频道仍占设备主人自己的配额。

持久占用：MySQL 固定玩家槽位；实际票据：NeoForge UUID TicketController；运行资格：有界租约。玩家离线不撤销占用；进程停止无法运行世界，但占用仍存在。Redis 心跳过期不会释放持久名额。

开启先在 SQL 玩家行锁下预留，再在游戏线程安装设备所在区块的 ticking 票据，最后确认；失败可明确补偿，结果未知保留预留待恢复。关闭先标记撤销，再撤票据、确认释放槽位。远程关闭离线服设备可能显示待撤销，不会在无法确认旧加载资格失效时重新分配。

启动回调先清理本模组保存票据，异步获取合法授权后主动恢复，不依赖该方块先 tick。不同设备的票据分别引用相同区块，只释放本模组该设备的票据。Minecraft 引擎票据可带来邻近区块连带驻留；没有承诺物理上只多加载一个区块。

拆除有资产的方块会封存并保留日志；掉落物是无余额、无领取凭证的普通方块。结构/创造复制带旧 ID 的实例会因坐标/世界/状态冲突暂停；普通重新放置生成新 ID。封存后原坐标可能暂时不可重新注册，需安全恢复回收旧记录，而不是清表。
