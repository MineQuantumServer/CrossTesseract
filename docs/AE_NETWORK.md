# AE2 两层能力与未完成目标

**本项目未实现独立 JVM 间的 AE 原生网络合并。** “传输频道”始终是自己的 SQL 资源频道，不是把 AE_CHANNEL=32 作为普通余额。两个 JVM 不共享 IGridNode、IGrid、控制器或 crafting CPU 对象。

## Level 1：实际物资网关

每设备通过公开 GridHelper 创建真实 IManagedGridNode，挂载自己的本地独占可取存储；有 channel/power 才工作。同步 insert/extract 只读写本地受限缓冲，不等数据库。异步需求经过共享 SQL 划拨和本地 WAL 后到货，才通知原生 AE 缓存。不会多个子服同时依据同一余额快照提取。

开启 AE 物资桥后可打开“库存”页，按规范化资源/组件哈希分页查看本地立即可取、频道远端已知余额、当前设备独占预留、已记 LOCAL 但尚未应用本地的在途数量及不可达/隔离数量。远端余额是有权限的 SQL 观测，不包含其他设备的独占库存，不保证下一次提取一定成功；SQL 的 LOCAL 记录也不能冒充游戏世界已保存。同步 MEStorage 仍只暴露本地可用凭证。每次读取最多八行，载荷仅留在服务端，客户端收到名称/翻译键、数量、状态和当前玩家自己的请求。

选择资源、输入数量并“调货”会创建持久请求。V004 `ct_stock_requests` 按群组/设备/频道/资源和服务端 actor 记录幂等键、初始/未分配数量、状态和六十秒期限。每设备最多八个待分配请求；终态保留三十天，计入现有每服历史容量和有界清理。请求只有需求，不持有第二份资产。既有频道轮转分配器依据首个请求的资源哈希申请独占划拨；公平性、SQL 权限/fencing、接收容量、WAL 和原生到货通知均复用原路径。请求等待当前资源至过期，同类型后续请求可能暂时被阻挡，但不会阻止其他端点/资源类型。

实际 AE extract 遇到本地不足时立即返回本地已取数量，并异步记录短缺需求；同一资源最多两秒触发一次、缓存最多十六个标识，已有未分配需求合并。simulate 不创建请求。按钮只确认“需求已记录”，不确认资源已到货；FULFILLED 表示需求已全部独占预留，到货可能仍在途。取消/到期只撤销未分配需求，不退款已有划拨；自动补货模式仍可按普通需求获取资源。切换频道取消旧频道未分配意图，已领取缓存仍须按原排空规则处理。

界面每两秒刷新，五秒后标记观测陈旧并停用调货；设备版本随快照提交，陈旧页面不能给新绑定套用旧资源请求。网络分区和权限变化不具有瞬时撤权保证，关键请求和划拨各自执行 SQL 权限验证。发送模式显示接收方向关闭并停用调货按钮；缺注册项、过滤拒绝、原生网失电或权限暂停有不可用原因，频道内其他资源仍保留。全部未知组件和复杂 AE 子网/存储别名并未全面验证。

## Level 2：可运行的实验代理

默认关闭，启动参数 `-Dcross_tesseract.aeNetworkPrototype=true`（开发 runs 用 `-PaePrototype`）。本地真实网格广告携带 grid UUID、native usedChannels、供电/控制器状态，SQL 再验证传输频道权限、端点状态、session epoch、peer lease 及协商的 ae_proxy 能力。多个桥在同一实际网格使用同一 identity，只选一个 leader 广告/维护代理，不同传输频道绑到同一网格时拒绝该代理语义。

远端需求映射为本地真实 REQUIRE_CHANNEL 非 in-world shadow managed nodes，连接本地 grid pivot，实际消耗频道及电力，不是计数变量。每两秒最多改变四个节点，最多 32 个代理节点；peer 资格最多五秒有效，失权/暂停清理代理节点。新广告减去代理本身的已用频道，防止互相再次把代理计作新需求而扩大。

该方案在本地路径/电力服务上施加真实约束，但 **没有合并** 原生控制器寻路、电力池、安全数据库、存储服务对象、合成任务或请求服务。供电各服独立，多个控制器保守拒绝，网络不存在“跨服原生 cable 的完全等价性”。通道预留并不自动带来跨服 crafting CPU 可见性。

## 具体技术缺口

公开 API 中的 IGrid/IGridNode 等标记不应自行实现的接口没有被伪实现。要扩展为真正跨服网络，需要单独定义控制器/路径授权、频道负担、各服电力责任、统一安全边界、服务路由及 crafting task 的持久身份/取消/恢复；原生服务大量持有同 JVM 的对象和同步调用。代理这些服务会有可见语义差异，必须分别测试、记录，而不能仅同步频道数量后声称原生网络已合并。

没有实施版本敏感 Mixin。若未来确实需要，应隔离到精确 SHA/版本的模块，并加入目标方法/字节码检测和失效关闭。目前完整原生频道目标为**未完成**，真实代理原型不把其计作验收通过。
